Assistant — политика конфиденциальности / Privacy policy

Обновлено 30.10.2026.

Что это

«Assistant» — личное приложение одного пользователя (владельца этого аккаунта Google). Оно не распространяется, не имеет других пользователей и не предлагается третьим лицам.

Какие данные Google используются

Через Google Calendar API приложение читает события календарей владельца и записывает события в его календарь «Assistant». Данные используются только для показа и ведения его собственного расписания в его личной базе данных.

Передача третьим лицам

Данные никому не передаются, не продаются и не используются для рекламы. Доступ есть только у владельца.

Хранение и удаление

Копии событий хранятся в личной базе владельца и удаляются при отзыве доступа (Google Account → Security → Third-party access) или по его команде.
